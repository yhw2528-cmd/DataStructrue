===============================================================
              2025-05-15 트리(Tree) 자료구조 정리
===============================================================

[기본 개념]
- 트리: 비선형 자료구조, 계층적 구조를 표현
- 이진트리: 자식이 최대 2개인 트리
- 완전이진트리: 마지막 레벨을 제외한 모든 레벨이 꽉 차고,
               마지막 레벨은 왼쪽부터 채워진 트리

[이진트리 수학적 성질]
- n개의 노드를 가진 트리는 반드시 n-1개의 간선을 가진다
- 높이가 h인 이진트리: 최대 2^h - 1개의 노드를 가진다
- n개의 노드를 가진 이진트리의 높이: ceil(log2(n+1))

[공통 노드 구조체]
  typedef char TElement;
  typedef struct TNode {
      TElement data;
      struct TNode *left;
      struct TNode *right;
  } TNode;

===============================================================
 1. TreeRep.c — 이진 트리 표현 (동적 메모리)
===============================================================

[핵심 함수]
  TNode *create_tree(TElement data, TNode *left, TNode *right)
  - malloc으로 노드를 동적 할당하고 data, left, right를 설정 후 반환

  void delete_tree(TNode *n)
  - 후위순회(postorder) 방식으로 재귀적으로 트리 전체 메모리 해제
  - 순서: 왼쪽 서브트리 → 오른쪽 서브트리 → 현재 노드 free()

[main에서 구성한 트리]
  root1 (일반 이진트리):
            A
           / \
          B   C
         / \ /
        D  E F

  root2 (왼쪽 편향 트리):
        A
       /
      B
     /
    C
   /
  D

[핵심 포인트]
- 동적 할당(malloc)으로 트리를 생성하므로 반드시 delete_tree()로 메모리 해제 필요
- delete_tree는 후위순회를 이용해 자식을 먼저 해제하고 부모를 나중에 해제

===============================================================
 2. TreeTraversal.c — 이진 트리 순회 (Traversal)
===============================================================

[3가지 순회 방식]
  #define VisitNode(n) (printf("[%c]", (n)->data))

  preorder (전위순회):   루트 → 왼쪽 → 오른쪽
  inorder  (중위순회):   왼쪽 → 루트 → 오른쪽
  postorder(후위순회):   왼쪽 → 오른쪽 → 루트

[구현 코드 패턴]
  void inorder(TNode *n) {
      if (n != NULL) {
          inorder(n->left);    // 왼쪽 서브트리
          VisitNode(n);        // 루트 방문
          inorder(n->right);   // 오른쪽 서브트리
      }
  }

[main에서 구성한 트리]
          A
         / \
        B   C
       / \ /
      D  E F

[순회 결과]
  In-Order  (중위): [D][B][E][A][F][C]
  Pre-Order (전위): [A][B][D][E][C][F]
  Post-Order(후위): [D][E][B][F][C][A]

[TreeRep과의 차이]
- TreeRep.c: 동적 할당(malloc) 사용 → delete_tree() 필요
- TreeTraversal.c: 스택(지역변수) 직접 초기화 → 메모리 해제 불필요
  예) TNode d = {'D', NULL, NULL};  (스택에 바로 할당)

===============================================================
 3. BinSrchTree.c — 이진 탐색 트리 (Binary Search Tree)
===============================================================

[BST 성질]
- 왼쪽 서브트리의 모든 키 < 루트의 키 < 오른쪽 서브트리의 모든 키
- 탐색, 삽입, 삭제 평균 시간복잡도: O(log n)

[주요 매크로]
  #define KEY(n) (n->data)
  #define VisitNode(n) (printf("[%d]", (n)->data))

[핵심 함수]

  TNode *_search_bst(TNode *root, int key)
  - 재귀적 탐색: key < 현재 → 왼쪽, key > 현재 → 오른쪽
  - 찾으면 해당 노드 반환, 없으면 NULL 반환

  void insert_bst(TNode *root, TNode *n)
  - 재귀적 삽입: BST 성질에 맞는 위치에 리프로 삽입
  - 중복 키: 삽입하지 않고 free(n)으로 메모리 해제

  TNode *delete_bst(TNode *root, int key)
  - 삭제는 3가지 경우로 처리:
    case 1 (리프 노드):       자식이 없으면 바로 free()
    case 2 (자식 1개):        자식 노드로 부모와 직접 연결 후 free()
    case 3 (자식 2개):        오른쪽 서브트리의 최솟값(inorder successor)으로
                              현재 노드 데이터를 덮어쓰고, 그 successor를 삭제

[main 실행 순서]
  삽입 키: {35, 18, 7, 26, 3, 68, 22, 30, 99}
  삽입 후 BST:
              35
            /    \
          18      68
         /  \       \
        7   26      99
       /   /  \
      3   22  30

  탐색 테스트:
    26 탐색: 성공
    25 탐색: 실패

  삭제 테스트:
    case1: <3>  삭제 (리프 노드)
    case2: <68> 삭제 (자식 1개: 오른쪽에 99)
    case3: <18> 삭제 (자식 2개: inorder successor = 22)
    case3: <35> 삭제 (자식 2개: inorder successor = 26)

[삭제 case3 핵심 코드]
  TNode *succ = n->right;
  while (succ->left != NULL) succ = succ->left;  // 오른쪽 서브트리 최솟값 탐색
  n->data = succ->data;                           // 데이터 복사
  n->right = delete_bst(n->right, KEY(succ));     // successor 재귀 삭제
