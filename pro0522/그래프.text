## 그래프 정리

- 비선형 자료구조
- 객체 간의 관계를 표현하는 자료구조
- 예시: 지하철 노선도, SNS 인맥 관계 등

그래프 G는 (V, E)로 표시
- 정점(vertex): 노드라고도 함
- 간선(edge) 혹은 링크(link): 정점 간의 관계


---

## 그래프의 종류

### 무방향 그래프 (Undirected Graph)
- 간선을 통해 양방향으로 갈 수 있음
- (A, B)로 표현
- (A, B) = (B, A)

### 방향 그래프 (Directed Graph / Digraph)
- 간선을 통해 한쪽 방향으로만 갈 수 있음
- <A, B>로 표현 (A→B)
- (A, B) ≠ (B, A)

### 가중치 그래프 (Weighted Graph)
- 네트워크(Network)라고도 함
- 간선에 비용이나 가중치가 할당된 그래프
- 예시
  - 정점: 각 도시
  - 간선: 도시를 연결하는 도로
  - 가중치: 도로의 길이

### 부분 그래프 (Subgraph)
- 정점 집합 V(G)와 간선 집합 E(G)의 부분 집합으로 이루어진 그래프


---

## 그래프 관련 용어

### 인접 정점 (Adjacent Vertex)
- 하나의 정점에서 간선에 의해 직접 연결된 정점

### 차수 (Degree)
- 하나의 정점에 연결된 다른 정점의 수
- 무방향 그래프: 모든 정점의 차수의 합 = 간선 수 × 2
- 방향 그래프:
  - 진입 차수 (in-degree): 해당 정점으로 들어오는 간선의 수
  - 진출 차수 (out-degree): 해당 정점에서 나가는 간선의 수
  - 모든 진입(진출) 차수의 합 = 간선의 수


---

## 그래프의 경로 (Path)

### 경로란?
- 정점 A에서 정점 B까지 간선을 통해 이동하는 정점의 순서열
- 무방향 그래프: A-B-C 처럼 연결된 정점들의 나열
- 방향 그래프: 간선의 방향을 따라 이동 가능한 경우에만 경로 성립

### 경로의 길이 (Path Length)
- 경로를 구성하는 데 사용된 간선의 수

### 단순 경로 (Simple Path)
- 경로 중에 반복되는 정점(간선)이 없는 경로

### 사이클 (Cycle)
- 시작 정점과 종료 정점이 동일한 경로
- 단순 경로이면서 시작=끝인 경우


---

## 특수한 그래프

### 연결 그래프 (Connected Graph)
- 무방향 그래프에서 모든 정점 쌍 사이에 경로가 존재하는 그래프
- 연결되지 않은 그래프 → 비연결 그래프 (Disconnected Graph)

### 트리 (Tree)
- 그래프의 한 종류
- 사이클이 없는 연결 그래프
- 정점이 n개이면 간선은 반드시 n-1개

### 완전 그래프 (Complete Graph)
- 모든 정점이 서로 연결된 그래프
- 정점이 n개일 때 간선의 수 = n × (n-1) / 2  (무방향)
- 정점이 n개일 때 간선의 수 = n × (n-1)      (방향)

## 그래프의 표현 방법

### 1. 인접 행렬 (Adjacency Matrix)
- 2차원 배열 adj[n][n]으로 표현 (n = 정점 수)
- adj[i][j] = 1  →  정점 i에서 j로 가는 간선 있음
- adj[i][j] = 0  →  간선 없음
- 가중치 그래프는 0/1 대신 가중치 값 저장
- 장점: 간선 존재 여부를 O(1)로 확인 가능
- 단점: 정점이 많고 간선이 적으면 공간 낭비 (O(n²))

#### 무방향 그래프 (Undirected Graph)
- (A,B) 간선이 있으면 adj[A][B] = 1, adj[B][A] = 1 동시에 설정
- 행렬이 대각선을 기준으로 대칭 (adj[i][j] = adj[j][i])

예시: A-B, A-D, B-C, C-D 간선이 있을 때

```
    A B C D
A [ 0 1 0 1 ]
B [ 1 0 1 0 ]
C [ 0 1 0 1 ]
D [ 1 0 1 0 ]
```

#### 방향 그래프 (Directed Graph)
- <A,B> 간선이 있으면 adj[A][B] = 1만 설정 (adj[B][A]는 별개)
- 행렬이 비대칭일 수 있음 (adj[i][j] ≠ adj[j][i])
- 행(row) i의 합 = 정점 i의 진출 차수 (out-degree)
- 열(col) j의 합 = 정점 j의 진입 차수 (in-degree)

예시: A→B, A→D, B→C, D→C 간선이 있을 때

```
    A B C D
A [ 0 1 0 1 ]   ← A에서 나가는 간선: B, D
B [ 0 0 1 0 ]   ← B에서 나가는 간선: C
C [ 0 0 0 0 ]   ← C에서 나가는 간선: 없음
D [ 0 0 1 0 ]   ← D에서 나가는 간선: C
```

### 2. 인접 리스트 (Adjacency List)
- 각 정점마다 연결된 정점들을 연결 리스트로 저장
- 장점: 간선이 적을 때 공간 효율적 (O(V + E))
- 단점: 간선 존재 여부 확인이 O(degree)

```
A → B → D
B → A → C
C → B → D
D → A → C
```

## 그래프 탐색

### DFS (깊이 우선 탐색, Depth First Search)
- 시작 정점에서 출발, 갈 수 있는 만큼 깊이 들어가다가 막히면 되돌아옴
- 스택(Stack) 또는 재귀(Recursion)로 구현
- 순서: 방문 → 인접 정점 중 미방문 정점으로 이동 → 반복

```
의사코드:
DFS(v):
    v 방문 표시
    v의 인접 정점 w에 대해:
        if w 미방문:
            DFS(w)
```

### BFS (너비 우선 탐색, Breadth First Search)
- 시작 정점에서 출발, 인접한 정점을 모두 먼저 방문 후 다음 단계로 이동
- 큐(Queue)로 구현
- 최단 경로 탐색에 유리

```
의사코드:
BFS(v):
    v 방문 표시, 큐에 삽입
    while 큐 not empty:
        u = 큐에서 꺼냄
        u의 인접 정점 w에 대해:
            if w 미방문:
                w 방문 표시, 큐에 삽입
```

| 구분 | DFS | BFS |
|------|-----|-----|
| 자료구조 | 스택/재귀 | 큐 |
| 특징 | 깊이 우선 | 너비 우선 |
| 최단 경로 | X | O (가중치 없는 그래프) |
| 공간복잡도 | O(V) | O(V) |

## 신장트리 (Spanning Tree)

### 정의
- 그래프 G의 모든 정점을 포함하면서 사이클이 없는 부분 그래프
- 정점이 n개이면 간선은 반드시 n-1개
- 연결 그래프라면 항상 신장트리가 존재
- 하나의 그래프에서 신장트리는 여러 개 가능

### 성질
- 모든 정점이 연결되어 있음 (연결성)
- 사이클이 없음 (비순환성)
- 간선 수 = 정점 수 - 1

### 신장트리 생성 방법
- DFS 기반: DFS 탐색 중 실제로 방문에 사용된 간선만 선택
- BFS 기반: BFS 탐색 중 실제로 방문에 사용된 간선만 선택

```
의사코드 (DFS 기반):
DFS_Spanning(v):
    v 방문 표시
    v의 인접 정점 w에 대해:
        if w 미방문:
            간선 (v, w)를 신장트리에 추가
            DFS_Spanning(w)
```

## 최소비용 신장트리 (MST, Minimum Spanning Tree)

### 정의
- 가중치 그래프에서 신장트리 중 간선 가중치의 합이 최소인 신장트리
- 네트워크 설계, 도로망 최적화 등에 활용

### 응용 예시
- 도시들을 연결하는 도로 건설 → 최소 비용으로 모든 도시 연결
- 통신 케이블 네트워크 설계
- 전력망 설계

---

### 크루스칼 알고리즘 (Kruskal's Algorithm)

- **핵심 아이디어**: 가중치가 작은 간선부터 탐욕적으로 선택, 사이클을 형성하는 간선은 제외
- **Union-Find (서로소 집합)** 자료구조로 사이클 판별
- 시간복잡도: O(E log E)  (간선 정렬이 지배)

```
알고리즘:
1. 모든 간선을 가중치 오름차순으로 정렬
2. 각 정점을 독립적인 집합으로 초기화
3. 가중치 작은 간선부터 순서대로:
   - 간선 (u, v)의 두 정점이 다른 집합이면 → MST에 추가, 두 집합 합병
   - 같은 집합이면 → 사이클 형성, 제외
4. 간선 수 = n-1이 되면 종료
```

예시 (정점 6개, A~F):
```
간선 정렬: B-C(1), E-F(1), A-D(2), D-E(2), A-B(3), A-E(4), C-D(4), B-F(5), C-F(6)

선택: B-C(1) → 선택: E-F(1) → 선택: A-D(2) → 선택: D-E(2) → 선택: A-B(3)
                                                  (A,D,E,F 연결)   (모든 정점 연결)
MST 총 비용: 1+1+2+2+3 = 9
```

---

### 프림 알고리즘 (Prim's Algorithm)

- **핵심 아이디어**: 하나의 정점에서 시작해서 MST를 점진적으로 확장
- 현재 MST에 포함된 정점과 미포함 정점을 잇는 간선 중 최소 가중치 선택
- 시간복잡도: O(V²)  (인접 행렬), O(E log V) (우선순위 큐 사용 시)

```
알고리즘:
1. 임의의 시작 정점 선택, MST 집합에 추가
2. MST 집합에 포함된 정점과 연결된 간선 중 최소 가중치 간선 선택
   (단, 해당 간선의 반대쪽 정점이 MST에 미포함이어야 함)
3. 해당 정점을 MST에 추가
4. 모든 정점이 MST에 포함될 때까지 2~3 반복
```

예시 (정점 A에서 시작):
```
시작: A 선택
→ A에서 최소: A-D(2) 선택
→ {A,D}에서 최소: D-E(2) 선택
→ {A,D,E}에서 최소: E-F(1) 선택
→ {A,D,E,F}에서 최소: A-B(3) 선택
→ {A,B,D,E,F}에서 최소: B-C(1) 선택
MST 총 비용: 2+2+1+3+1 = 9
```

| 구분 | 크루스칼 | 프림 |
|------|---------|------|
| 접근 방식 | 간선 중심 | 정점 중심 |
| 자료구조 | Union-Find | 배열 or 우선순위 큐 |
| 시간복잡도 | O(E log E) | O(V²) or O(E log V) |
| 유리한 경우 | 간선이 적은 희소 그래프 | 간선이 많은 밀집 그래프 |
